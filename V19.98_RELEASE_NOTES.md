# Private Navigation Toolbox V19.98

## Liquid Glass Manager Refactor

- Removed the experimental manager real-time monitoring strip and its injected sampler. The existing seven-day activity chart remains.
- Made the seven-day activity chart read from authenticated Cloudflare D1 activity records only. Browser-local history is retained as a migration/retry queue, not shown as if it were cloud data. Failed D1 reads are labeled explicitly.
- Changed the system-console activity waveform to use the same D1 activity snapshot, so Chrome and Edge do not plot separate localStorage histories.
- Replaced native manager `<select>` presentation with a shared custom liquid-glass dropdown layer. The original select elements remain in the DOM and continue to drive existing handlers/forms.
- Replaced website-row disclosure menus with directly visible **Edit** and **Recycle** actions.
- Replaced category-row disclosure menus with directly visible icon/title/rename/delete actions.
- Reworked the category header into one compact search + count + add toolbar. The create form opens only on demand; category icon matching and order-reset tools remain available in a compact tools row below the directory.
- Updated the activity API read window to cover seven local calendar-day buckets across time zones; the dashboard still displays exactly seven local dates.
- Updated root and app release metadata to V19.98.

## Deployment

Deploy the complete ZIP to the existing Cloudflare Pages/GitHub project root. Do not upload only `cn/index.html`: the new CSS/JS assets and the activity API change are part of this release. No D1 table reset or data migration is required.

## Compatibility and verification notes

- The app Content Security Policy now permits same-origin CSS/JS assets (`'self'`) while retaining the existing inline-script/style allowance. This is required for the versioned manager UI assets to load in supported browsers.
- Updated both root and `/cn/` document titles, export/backup fallback version strings, app metadata, and API metadata to V19.98.
- Static checks: 16 embedded JavaScript blocks pass `node --check`; all shipped JavaScript files pass syntax checks; CSS parses without errors; no duplicate static HTML IDs; ZIP integrity verified.
- A live authenticated D1/Workers browser regression was not run in this environment. The release does not alter D1 schema or data rows; verify admin login, activity GET/POST, and one sync after deployment.
