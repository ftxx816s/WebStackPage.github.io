# Private Navigation Toolbox V20.00 · Local-first loading and offline shell

Release date: 2026-11-13
Base: `Private_Navigation_Toolbox_V19.99_Clock_Tick_Ring_Expansion.zip`

## Loading architecture

- First paint no longer waits for the manager-only CSS/JS bundle. The manager enhancements are loaded only when the management drawer is opened.
- Root `/` redirects from the document head, avoiding a separate painted loader page before `/cn/`.
- A complete validated D1 snapshot still hydrates synchronously from the existing localStorage cache before the first render.
- On a fresh browser without a D1 cache, the existing public seed (191 built-in sites / 20 categories) hydrates immediately; D1 then fills in the current full snapshot in the background. Local favorites, recents, custom sites, and local preferences are preserved.
- Pending administrator writes are restored before any network request. If the session is verified and a complete cached admin snapshot exists, that snapshot becomes the safe offline baseline so edits can enter the existing pending-write queue. Without a verified full snapshot, management actions remain read-only until D1 is ready. Existing conflict protection, authentication, `/api/data`, schemaVersion 3, D1 and KV contracts remain unchanged.
- Cloud D1 reads and authentication checks have shorter failure timeouts; write timeouts are unchanged. D1 polling is reduced from 5 seconds to 15 seconds.

## Offline and cache behavior

- Added root-scoped `sw.js`: cached app shell uses stale-while-revalidate; same-origin static assets use cache-first. `/api/*` is explicitly network-only and is never cached.
- Service Worker precaches the app shell, theme wallpaper, icons, font, and manager-only assets after the first successful load. Offline shell availability requires one successful online installation first.
- Existing localStorage snapshot and pending-write queue remain the synchronous boot/recovery source. IndexedDB remains the storage for large user wallpapers; it is intentionally not used for the small navigation bootstrap because IndexedDB is asynchronous.
- Liquid Glass wallpaper now restores local IndexedDB/legacy wallpaper first; Cloudflare wallpaper state is checked in the background and replaces the local image only after the remote image decodes. Wallpaper polling is reduced from 5 seconds to 30 seconds.
- Converted the bundled 1920×1080 default wallpaper to WebP to reduce transfer size while retaining dimensions.

## Compatibility preserved

- Existing `/api/data` and `/api/state` routes, D1 schemaVersion 3, D1/KV bindings, wallpaper API, authentication, five themes, navigation, categories, favorites, recents, admin management, backups, and conflict handling are unchanged.
- No D1 schema migration or production data write is required for this release.
- The `functions/api/data.js` API version remains 19.99; only the front-end app version is 20.00.

## Verification

- JavaScript syntax checked for all inline scripts, service worker, manager runtime, and Cloudflare Functions.
- HTML parse, static IDs, seed row counts, asset paths, service-worker cache list, and ZIP CRC integrity checked.
- Existing backend Functions are included unchanged from the V19.99 source package.
- Live Cloudflare deployment and real-browser network regression are not available in this build environment; deploy the full ZIP and test Chrome/Edge on both direct and VPN connections.

## Deployment

Deploy the complete ZIP to the existing Cloudflare Pages/GitHub project root. Do not upload only `cn/index.html`; the release includes the Service Worker, optimized wallpaper asset, existing runtime assets, and existing Functions. No D1 schema migration is required.
